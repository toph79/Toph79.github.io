Selected work

Active Rear Steer

Steers the buggy's rear wheels with a Teensy 4.0, a VNH5019 motor driver and a cascaded PID loop running at up to 1 kHz. Onboard sensors showed a 20% smaller turning radius and an 8% faster lap.

C++ · Teensy 4.0 · CAN · Altium Rev 2 controller in layout

CAN Test Bus

My first Altium board. Six JST ports pass the bus through to a CAN transceiver, with test hooks for CAN H, CAN L, 5 V and ground. A Teensy 4.0 reads the traffic and shows it on an I2C LCD. It sped up bring-up for the next three boards on the car.

Altium · CAN · C++ Sub-team lead

Baja DAQ Sensor Network

Plug-and-play CAN sensor nodes on XIAO ESP32-S3 boards at 1 Mbit/s. The hub logs raw timestamps to SD and sends 10 Hz summaries to the pit over an XBee-PRO 900HP radio. I lead a team of five.

ESP32-S3 · CAN · XBee Bench demo Nov 30, 2026

Real-Time Object Detection

A PyTorch model that finds the head and body of characters in live video game footage.

Python · PyTorch

Song Splitter

Splits a song into bass, drums, vocals and everything else using Demucs, a PyTorch model. It reads the audio as a waveform for timing and as a spectrogram for pitch, and a transformer lets the two share context. Long songs run in overlapping chunks that are crossfaded back together.

Python · PyTorch · Demucs
