# Toph79.github.io

Personal portfolio site for Toph Jones. Plain HTML, no build step.

## Publish
1. Create a public repo on GitHub named exactly `Toph79.github.io`.
2. Upload everything in this folder (keep the `images/` folder).
3. The site goes live at https://toph79.github.io within a minute or two
   (Settings → Pages shows the status).

## Update
- Text and projects: edit `index.html`.
- Board images: replace files in `images/` with the same names.
- Resume: replace `resume.pdf`.
